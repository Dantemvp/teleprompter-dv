## Escena 01

## Escena 02
DRA: El más obvio. El refresco. Diez cucharadas de azúcar en un vaso.
// PANTALLA — ✱ EL MÁS OBVIO

## Escena 03
DRA: El más disfrazado. El jugo natural. Le quitaste la fibra a la fruta y entra casi igual de rápido.
// PANTALLA — ✱ EL MÁS DISFRAZADO

## Escena 04
DRA: El que nadie sospecha. Dormir mal. Una noche de cinco horas ya te deja peor respondiendo al día siguiente.
// PANTALLA — ✱ EL QUE NADIE SOSPECHA

## Escena 05
DRA: El más terco. El estrés. El cortisol te sube el azúcar aunque no te hayas llevado nada a la boca.
// PANTALLA — ✱ EL MÁS TERCO

## Escena 06
DRA: El más silencioso. Picar entre comidas. Cada vez que picas, tu páncreas vuelve a trabajar, aunque sea algo sano.
// PANTALLA — ✱ EL MÁS SILENCIOSO

## Escena 07
DRA: El más subestimado. No tener músculo. Es el órgano que más azúcar se lleva, y si no lo entrenas, nadie lo recoge.
// PANTALLA — ✱ EL MÁS SUBESTIMADO

## Escena 08
DRA: (señalas al lente) Y el más fácil de todos. Seguirme, para que no te agarren desprevenida. Comenta cuál no te esperabas. Sigue a tu Dra. Fedra Aldama para más salud. Chao :*
// PANTALLA — ✱ EL MÁS FÁCIL DE TODOS
