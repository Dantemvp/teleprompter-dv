## ESQUELETO (5 pasos, siempre los mismos)

**1 · Saludo de siempre** — el que ya usa, sin cambiarlo.
**2 · La novedad + el número cerrado** — "acaban de llegar CUATRO propuestas de ___".
**3 · Pieza por pieza** — y aquí van los 4 golpes de cada una (abajo).
**4 · La comparación** — cuál es para qué. Aquí es donde la clienta decide.
**5 · Cierre con urgencia honesta + CTA.**

---

## PASO 1 — Saludo

VOZ: Hola hola, ¿qué tal, hermosas? ¿Cómo están?
// PANTALLA — Bianca de cuerpo completo, ya con la primera pieza puesta. Detrás, el rack lleno.
// ✱ Arranca YA con la prenda puesta. Nada de intro, nada de "bienvenidas a un nuevo video".

## PASO 2 — La novedad y el número

VOZ: Nos acaban de llegar ______ propuestas de ______ y se las voy a enseñar una por una.
// ✱ El número cerrado es lo que retiene. "Cuatro propuestas" hace que se queden a ver las cuatro.
// ✱ Si de verdad acaban de llegar, dilo. Si no, di "les traigo" y ya. Nunca inventes la novedad.

VOZ: Empezamos con la que traigo puesta.

## PASO 3 — Pieza por pieza (repetir el bloque por cada una)

// ✱ CADA PIEZA LLEVA ESTOS 4 GOLPES, EN ESTE ORDEN. Son 15–20 segundos por pieza.

**① CÓMO SE PORTA LA TELA** — la palabra que la clienta necesita oír.
VOZ: Este es rígido / semi rígido, sí alcanza a estirar / este estira y estira muchísimo.
// ✱ Demuéstralo con las manos. Jala la tela frente a la cámara. Este gesto es el que la gente ve.

**② EL DETALLE QUE LA HACE DIFERENTE** — uno solo, el que se ve.
VOZ: Fíjense en ______ (el botón, la costura, el olán, el forro, el cierre, el bolsillo).
// ✱ Close up del detalle. El editor lo necesita separado.

**③ QUÉ TE HACE A TI** — el beneficio en el cuerpo, no en la prenda.
VOZ: Esta costura de aquí levanta / este corte alarga la pierna / este cuello estiliza el cuello.
// ✱ Gírate. De frente, de lado, de espalda. Sin apuro.

**④ DÓNDE LA USAS** — una situación concreta.
VOZ: Este te lo pones para ______ (la oficina, salir a cenar, el diario, una fiesta).
// ✱ Una situación, no tres. Concreta.

VOZ: Propuesta número ___.
// ✱ Cierra cada pieza nombrando el número. Ese "número dos" es lo que sostiene el video.

// ✱ TRANSICIÓN ENTRE PIEZAS: corte seco o cambio de prenda. Aquí el editor mete las transiciones del banco (ri- / re-).

## PASO 4 — La comparación

VOZ: Entonces: si quieres algo que aguante y no se deforme, te vas por la ___. Si quieres comodidad, la ___. Y si vas a salir arreglada, la ___.
// PANTALLA — split o cortes rápidos de las piezas, una tras otra.
// ✱ Este paso no está en la referencia y es el que la mejora. Le resuelve la decisión a la clienta.

## PASO 5 — Cierre

VOZ: De estas nos llegaron poquitas de cada talla, así que si te late alguna, no te esperes.
// ✱ Solo dilo si es verdad. Esto conecta con g-53 (por qué se agota tan rápido).

VOZ: Mándame mensaje con el número de la propuesta que te gustó y te digo si queda tu talla.
// PANTALLA — número de propuesta grande en pantalla sobre cada pieza.
// ✱ CTA por NÚMERO. "Me interesa la 3" es lo más fácil que le puedes pedir a alguien.
